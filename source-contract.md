# Organisational source and publishing contract

**State:** Bitbucket-ready proposal; confirm authority after import into CoM.

- **Bitbucket:** governed project working Markdown, reusable definitions and versioned experiments where designated.
- **Confluence:** endorsed project narrative, decisions, review outcomes and publication where designated.
- **Jira:** assigned delivery work, status, dependencies and committed dates.
- **Miro:** collaborative visual evidence; not automatic approval.
- **Teams:** user-provided meeting transcript and notes; evidence of discussion, not inherently ratified decisions.
- **Rovo CX Project Companion:** interpretation and approved maintenance support, not a new system of record.

When the user provides latest project evidence: inspect current target; distinguish fact, proposal and approval; prepare the smallest file change; confirm authority; apply only with authorised tools; verify read-back and downstream updates.

Current Rovo limitations: Bitbucket branch creation and commit/file editing have not been demonstrated. Supply ready-to-apply patch while those capabilities are unavailable. Never claim an edit occurred without confirmation.

Do not mirror raw CoM content to personal GitHub or Strategic OS. Future Strategic OS intake is a separately reviewed, approved abstraction, not historical repository synchronisation.
