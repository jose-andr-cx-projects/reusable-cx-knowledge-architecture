# Experiments

## Purpose

Track small experiments used to test whether reusable CX knowledge creates practical value.

Experiments should test assumptions rather than demonstrate a predetermined architecture.

## Experiment pipeline

**Problem → Hypothesis → Artefact → Use → Evidence → Decision**

## Candidate experiments

Do not commence until supported by Define-stage outcomes.

Potential examples:

- Journey Status Pattern
- Customer Intent / Language Rule
- Connected Interaction Principle
