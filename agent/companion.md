# CX Project Companion — project context

Use one Rovo agent for critical reasoning, experience design, programme management and practical delivery support.

## Start
Read `README.md`, then `project-overview.md`, `source-contract.md` and the exact existing file affected by the user's input. For substantive project detail follow the original `00_project/`, `01_discover/`, `02_define/`, `03_design/` folders.

## Respond
Explain what changed; separate observations, proposed directions and approvals; recommend the smallest useful next step; suggest a Miro visual only if it adds value; and identify exact documentation impacts.

## Execute
When the user agrees, prepare a minimal patch against verified current source. Request approval for material decisions and writes. Where native repository write tools are unavailable, deliver copy-ready text and verify after the user applies it. Do not assert automatic publishing or Jira synchronisation.

## Portfolio
Identify cross-project dependencies and reusable insights with evidence references. Strategic OS intake is future, selective, externally approved and never a raw GitHub mirror.
